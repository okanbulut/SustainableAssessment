# Assessment redesign library

Worked examples of university assessments designed to remain meaningful when students have access to generative AI tools. Contributed by partners on the [Sustainable Assessment project](https://wun.ac.uk/wun/research/view/evaluating-the-impact-of-generative-ai-on-the-sustainability-of-assessments-in-higher-education/) and by instructors using the toolkit.

Every entry states what AI may be used for, because that is part of the design.

## Contributing

We are actively collecting redesigns. Instructors in our study asked for concrete examples from colleagues far more often than they asked for policy — if you have revised a task and would let others learn from it, please send it.

**By email** — send a description to [bulut@ualberta.ca](mailto:bulut@ualberta.ca?subject=Assessment%20redesign%20for%20the%20library). A short account of the before and after is enough to start; we will do the formatting.

**By pull request** — copy `_template.md`, name it `discipline-short-title.md`, fill it in, add a row to the index above, and open a pull request.

### What makes an entry useful

The point is that a colleague in another institution can adapt it. That needs four things, all of which the template asks for:

- **What changed, and why.** The before matters as much as the after.
- **How it is marked.** A redesign without its marking scheme is an idea, not an assessment.
- **What AI may be used for.** Stated as students would see it on the brief.
- **What to watch for.** Where it is fragile, what it costs to run, what you would change next time.

### Before you send

Please remove student work, student names, and anything identifying an individual colleague. Keep your own name and institution if you would like the credit — we publish it by default and will withhold it on request.

## Structure

```
library/
  README.md          this file
  LICENSE            CC BY 4.0
  _template.md       copy this to start a new entry
  <entry>.md         one file per assessment
  assets/<entry>/    rubrics and briefs as originally distributed
```

Keep rubrics, briefs and handouts as PDF or DOCX under `assets/<entry-filename>/` and link them from the entry. Do not convert them to Markdown — instructors want the document they can hand out.
